# Практична робота 2 — SQLite
## Варіант 1: Бібліотека

У практичній роботі використано таблицю `books` з Практики 1. Схему таблиці не змінювали. Додано один рядок, у якому жанр (`genre`) невідомий і записаний як `NULL`.

## Пояснення до Завдання 4

Для перевірки відсутнього значення використовується `IS NULL`, а для наявного значення — `IS NOT NULL`. Не можна коректно перевірити NULL через `= NULL`, тому що NULL означає невідоме значення, а порівняння з ним не дає TRUE. Для такої перевірки SQL має спеціальні оператори `IS NULL` та `IS NOT NULL`.

## Контрольні питання

**1. Чому WHERE price = NULL повертає порожній результат і що потрібно написати?**  
NULL означає відсутнє або невідоме значення, тому звичайне порівняння `= NULL` не дає TRUE. Щоб знайти такі рядки, потрібно написати `WHERE price IS NULL`, а для рядків, де значення є, — `WHERE price IS NOT NULL`.

**2. Чим WHERE відрізняється від HAVING?**  
`WHERE` відбирає окремі рядки таблиці до групування. `HAVING` застосовується після групування й відбирає вже сформовані групи, наприклад за результатом агрегатної функції.

**3. Коли варто уникати SELECT * і чому?**  
Варто уникати `SELECT *`, коли потрібні лише деякі стовпці. Явний перелік стовпців робить запит зрозумілішим, не повертає зайві дані та допомагає не залежати від змін структури таблиці.
